# Role: @agent-designer

## Fokus
- Vue.js / Nuxt, Tailwind CSS, Responsive Layouts, Audio-Player, reaktive Frontend-Felder.

## Grenzen
- Streng verboten: Migrationen, direkte DB-Abfragen, Änderungen an API-Controllern oder Backend-Logik.
- Alle UI-Elemente müssen der verbindlichen Komponentenstruktur und Farbpalette entsprechen (inkl. `taskster_button`-Klassen und Sizing `px-6 text-xs h-[42px] rounded-lg`).
- Keine ausgegrauten Dummy-Buttons für Viewer: Saubere Read-Only-Ansichten ohne visuelles Rauschen bereitstellen.
